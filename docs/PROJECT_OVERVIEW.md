# CitrusBrowser の全体像（経緯・体制・機能・設計の意図・方針）

更新日: 2026-11-21（1.0.2 の公開時点）。新しく作業を始める人・エージェントが、最初に読む資料です。詳しい進捗は [PROGRESS.md](PROGRESS.md)、規約は [AGENTS.md](../AGENTS.md)、今後の候補は [ROADMAP.md](ROADMAP.md) と GitHub Issues にあります。

## 1. 経緯

- **出発点**: Hazuki 氏のオープンソースの Android ブラウザ [Yuzu Browser](https://github.com/hazuki0x0/YuzuBrowser)（Apache-2.0、最終版 6.0.2・2021年）を、全コミット履歴ごと引き継いだ後継です。開発・管理は ajichama です。
- **段階**:
  1. ビルド基盤（Docker）
  2. 名前とパッケージ名の刷新（`io.github.ajichama.citrusbrowser`）
  3. ビルドと依存の刷新（JDK 21・Gradle 9.6・AGP 9.5・Kotlin 2.4）
  4. Android 16・17 への対応
  5. 広告ブロックと機能の強化（現在）
- **公開**:
  - 2026-11-21 に、CitrusBrowser としての版 **1.0.0** を GitHub Releases にテスト版として公開しました。続けて 1.0.1・1.0.2 を公開しています。
  - Google Play は、個人アカウントを登録済みで、公開を準備しています。

## 2. 制作の体制

- **人**: 利用者（オーナー）が方針を決めます。仕様の変更、メニューの変更、公開、費用やライセンスに関わる判断は、事前に説明して合意を取ります。
- **AI エージェント**: Claude Code（主な実装・検証）、OpenAI Codex、Antigravity が、同じリポジトリと手順書を共有して交代で作業します。
  - **引き継ぎ**: ローカルの引き継ぎ台帳（`.agents/handoff/`）と作業ロック（`tools/citrus-mcp`）を使います。
  - **手順**: 繰り返す手順は、Skills（`.agents/skills/`）に書いています。
- **ビルドと検証**:
  - JDK・SDK・Gradle・adb は、すべて Docker の中で使います（`scripts/docker-build.ps1`）。
  - 画面や WebView の動作は、Docker 上の Android エミュレーター（API 37）と、実機（SO-51D）で確かめます。
  - コミットの前に、ビルドと単体テストを通します。
- **公開の手順**:
  - Git の操作は `scripts/git-stage.ps1`・`git-commit-push.ps1` で行います。ステージするのは、明示したパスだけです。
  - リリース版は、Docker の専用ボリュームに置いた鍵で署名します（[RELEASE.md](RELEASE.md)）。

## 3. 作ってきた機能（Yuzu Browser からの主な追加・変更）

### 広告ブロック
- uBlock Origin 形式のフィルタの多くの構文に対応しています。
  - 通信の遮断と条件（domain・denyallow・to・method など）
  - redirect と redirect-rule
  - 要素の非表示（procedural を含む）
  - scriptlet（trusted を含む）
  - URL の書き換え（removeparam・urlskip）
- **scriptlet**: uBO と名前・引数だけを合わせた、独自の実装です（クリーンルーム）。
- **代替資源**（B 案）: 公開文書だけを根拠に自作しています。google-ima.js・adsbygoogle・fuckadblock・空の VAST/VMAP・無音の MP3/MP4 です。
- **フィルタリスト**: アプリに同梱せず、実行時に購読して取得します。
- **別アプリ**: GeckoView と uBlock Origin の原本（GPL）を組み込んだ検証用の別アプリ `:gecko-preview` もあります。本体とは別の applicationId で、保存領域も別です。

### 引き継ぎとデータ
- **Yuzu Browser からの取り込み**: Yuzu で書き出したデータを取り込めます。対象は、ブックマーク・履歴・スピードダイヤル・後で読む・設定・操作の割り当て・ユーザースクリプトなどです。

### 閲覧
- **アプリで開く**: リンクを、対応するアプリで開きます（X など）。
- **ページ情報**: 接続の安全性、遮断した数、サイトのデータの消去、タブを閉じたら自動で消去、ポップアップの許可を表示・操作できます。
- **閉じたタブを開き直す**: 初期で有効です。アプリを終了した後も、最大20件まで開き直せます。
- **ポップアップのブロック**: 利用者の操作によらないものを止め、サイトごとに許可できます。
- **プライベートタブ**: 通常のタブと並べて使えます。WebView のプロファイルで、Cookie・データを通常のタブと分けます。閉じたときと起動時に、データを消します。
- **画像の長押し**: 「画像をコピー」と、ダウンロードフォルダを使わない共有に対応しました。
- **アップロードでのカメラ撮影**: 画像・動画を受け付ける入力欄で、選択の画面に「写真を撮る」「動画を撮る」を並べます。`capture` 属性があれば直接カメラを開きます（Chrome と同じ。#13）。
- **ズーム禁止の無視**: 設定 › ページの設定でオンにすると、ページが viewport で拡大を禁止していても、ピンチで5倍まで拡大できます。既定はオフです（Chrome・Firefox と同じ。#17）。
- **QR コードの読み取り**: 検索の画面のボタンか、操作「QR コードを読み取る」から使えます。読み取った内容は入力欄に入れるだけで、開くかどうかは利用者が決めます。カメラは CameraX、解析は ZXing です（Google Play 開発者サービスは使いません。#18）。
- **PC 版サイトの切り替え**: そのタブだけ PC 版で表示します。
- **メニューの整理**: 「閉じたタブを開く」「新しいプライベートタブ」「ページのツール」を足しました。
- **検索**: 検索エンジンの設定を、初期値に戻せます。

### 安全性
- 外部から使えた部品（ファイル提供部分・デバッグ画面）を閉じました。
- ページから呼べる JavaScript インターフェースを、Android が推奨する仕組みに置き換えました。広告ブロックの scriptlet 用の1つだけは、合言葉で守って残しています。
- 共有・クリップボードで、ほかのアプリがファイルを読めなかった不具合（URI の二重スラッシュ）を直しました。
- **証明書エラーの警告**: 決定ボタンを「戻る」にし、「詳細」の先にだけ「それでも進む」を置く2段階にしました（#12）。

### Android の対応範囲
- minSdk は 24（Android 7.0）、targetSdk・compileSdk は 37 です。

## 4. 設計の意図と、決めた方針

- **Yuzu の使い勝手を土台にする**:
  - 画面と操作の体系は、Yuzu を引き継ぎます。
  - メニューや既定の動きを変えるときは、どう変わるかを示して、利用者の判断を受けてから行います。
- **既定を変えるときの扱い**:
  - 既定のメニューの変更は、新しく入れたときだけに効かせます。利用者が作ったメニューへは足しません（2026-11-21 決定）。
  - 不具合に近い初期値（閉じたタブ・ポップアップ）と、新機能の項目（画像をコピー）だけは、保存済みの設定にも1回だけ反映します。利用者が戻した値は、その後は変えません。
- **プライバシーと利便性**: プライバシーの機能で、タブの復元や後で読むなどの利便性を下げません。初期値はオフにするか、サイトごとの選択にします。
- **ライセンス**:
  - 本体は Apache-2.0 を守ります。GPL のコード（uBO・AdGuard の scriptlet や資源）は、参照も流用もしません。
  - uBO の原本との完全な互換が必要な用途は、GeckoView の別アプリが受け持ちます。
- **広告ブロックの方針**:
  - B 案で進めます。効果の大きい代替資源を、公開文書から自作します。
  - 成功の判定は、サイトごとのルールの追加ではなく、汎用の処理で行います。
  - YouTube 型の広告ブロック検知は、本体の成功条件に含めません（[ADBLOCK_STRATEGY.md](ADBLOCK_STRATEGY.md)）。
- **版番号**:
  - 1.0.0 から始めます。Yuzu の番号は引き継ぎません。
  - 内部の番号は「主版×1000000＋副版×1000＋修正版」です。旧版の移行処理が Yuzu の番号と比べるため、それより大きく保ちます。
- **配布**:
  - GitHub Releases（テスト版）と Google Play の両方で配ります。どちらも同じ署名の鍵を使い、Play では自分の鍵を Play App Signing に登録します。
  - プライバシーポリシーは GitHub Pages で公開しています（https://ajichama.github.io/CitrusBrowser/privacy/）。
  - Play では、正確な位置情報とアプリのインストール権限を残し、それぞれ申告します。

## 5. 今後の指針

- **基本機能の残り**: 2026-11-21 の洗い出しで挙げたものは、#18 までですべて対応しました。新しく見つけたものは Issue で管理します。
- **機能の候補**: ROADMAP の #1〜#9 です（HTTPS 優先、ピクチャーインピクチャー、タブのミュート、メディアの通知、プロファイル、タブグループ、GPC、追加のリスト、その他）。
- **Google Play**: 非公開テスト（12人以上・14日間）、各申告（位置情報・インストール権限・前景サービス）と説明動画、ストアの掲載情報を準備します。
- **依存の更新**: androidx.webkit と WorkManager は、使いたい機能が出てきた時点で更新します（minSdk 24 で可能になりました）。
