# 端末での確認手順

更新日: 2026-11-19。公開`f5f2ae8b`での11月17日の結果と、後続の追加検証を分けて記録します。

実施した結果と、これから確認する操作を分けて記録します。APKの生成と単体テストだけで、すべての操作を合格にしません。全体の状態は[進捗](PROGRESS.md)も参照してください。

11月17日の修正版は通常単体247件・buildSrc15件、debug・全計測APK・releaseのR8/lintが成功しました。新しい計測28件（移行13・広告7・検索4・UI2・HTTP更新2）と既存13件の計41件は、SO-51DのAndroid15/API35・WebView157.0.8103.50で失敗・スキップ0でした。

本体のGoogle.com日本語・記号検索、メニュー12項目・設定・IMEの一部も実描画で確認しました。Yuzuの実書出しは未作成、実データ取込は未確認です。広告は設定反映後に既知枠が非表示になりましたが、別系統の追従広告が残っています。41件成功をuBO相当の汎用遮断の成功とはしません。[内蔵方式の検証](ADBLOCK_ENGINE_PLAN.md)を別途進めています。

新しい設定反映回帰1件とGeckoViewの内蔵uBO検証は、この41件に含みません。一般的な不具合修正・新エンジンの確認は検証済みの公開版と分けて記録します。

## 2026-11-18の内蔵uBO検証（進行中）

独立した試作APKを同じSO-51Dへ導入し、起動・uBO 1.76.4の有効表示・ページ表示を確認しました。本体のアプリデータは共有していません。

内蔵uBOの標準設定画面も開き、日本語の設定項目とアプリ側のヘッダ・閉じる導線の実描画を確認しました。MyFiltersへの追加・保存、popup操作の詳細は今回の成功に含めません。

後続の手動確認では標準MyFiltersタブとpopupを開き、電源状態・遮断数・ダッシュボード等の操作導線の描画を確認しました。表示された遮断数だけで全広告の除去を保証しません。MyFilters本文の変更・保存とpopupの各機能は別の受け入れ対象です。

公開`14685f9e`の試作で、uBOを有効から無効に切り替え、UIで完了を確認してから対象アプリだけをforce-stopしました。再起動後のPIDが変わったことと、無効状態を保持したことを確認し、元の有効状態へ復旧済みです。保存profileでの有効状態1項目の手動確認であり、OS再起動・フィルタ本文やタブ全体のプロセス復元を証明したものではありません。

計測3件はテスト修正後に4.815秒で全成功、失敗・スキップ0でした。標準EasyListの通信遮断・要素非表示を親文書/子フレームでON/OFF比較し、正常scriptと本文表示も確認しました。画面再作成で同じSession・DOM・入力・JS状態・読込回数を保持し、危険な外部Intentを拒否、同一プロセスの画面再起動でも無効状態を保持しました。gzip通知のUTF-8・サイズ境界・破損拒否も成功しました。

初回の2失敗は、原本EasyListのloopback向けgenerichide例外と、外部Intent試験後のActivityScenario照合が原因でした。原本・製品挙動は変えずテスト条件だけ修正しました。試作を起動済みの保存プロファイルでの成功であり、新規プロファイルの冷間起動、OS再起動、scriptlet/procedural/MyFilters、実サイト全般は未確認です。

本体の設定リンク回帰は、起動追跡を修正した同じテストで公開旧版が11.651秒で失敗し、修正版へのデータ保持更新後は2.132秒で成功しました。1件で3つの内部リンクを確認しています。起動追跡に失敗していた最初の実行は製品の回帰証拠に含めません。

## 2026-11-19の本体操作境界

後続の共通操作API追加では、SO-51Dで本体の実機回帰3件が8.537秒で全成功しました。実`ActionExecutor.run`経由で履歴戻進・明示/切替操作による更新と停止・履歴ロック時の専用新規タブ・戻れない場合の既定更新を確認し、元タブのID/順序/選択と設定の同値を検証しています。専用data文書とloopback通信だけを使い、個人履歴と閉じたタブ履歴にfixtureを追加しません。

初回は更新直後のJS確認callbackが失われる競合を検出し、要求数の増加を先に待つテストへ修正しました。次の試行で起動待ちが失敗した時は端末が消灯/ロック中で、ユーザーの解除後に3件をまとめて再実行して成功しました。失敗した試行も成功件数へ加算しません。
