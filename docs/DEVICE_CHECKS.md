本体Hilt統合はローカルのfile://購読であり、外部HTTP購読は未確認です。SavedStateモデルの復元は、実Activityやプロセスを停止・再起動した結果ではありません。回線切替・OS再起動・Doze・実サイトでの誤遮断や性能・他OSも未確認です。OSSの非重なりも、横画面・別テーマ・ジェスチャーナビ等へ一般化しません。

## 準備

使用端末のOS、Android System WebViewのバージョン、APKのコミットとSHA-256を記録します。デバッグAPKで確認し、同じ署名の既存インストールがある場合は更新インストールで設定・保存データが残ることも確認します。署名が異なるときは、データを削除せず確認方法を相談します。

公開する記録には接続用IP・ペアリングコード・端末serial・個人画面を含めません。実機確認用スクリーンショットも公開しません。

最初は利用可能な1台で確認し、その後、対応下限API 23と最新OSを含めて範囲を広げます。接続・インストールは端末の所有者が許可した方法で行います。

バックグラウンド処理はOSの制約を受けるため、画面を閉じた直後に必ず実行されることを合格条件にはしません。強制停止中の実行も保証しません。再試行・再起動・設定変更によって、古い要求が削除済みの購読を復活させないことを重視します。

不具合の報告には、再現操作、期待した動作、実際の動作、OSとWebViewのバージョン、APKのコミットを添えます。ログに閲覧URLや認証情報が含まれる場合は、そのまま公開しません。
