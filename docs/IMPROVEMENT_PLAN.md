## 移行するデータの確認

| データ | 対応と保持方針 |
| --- | --- |
| 全体設定・アクション | 型と既知IDを検証する。アプリの版管理値や旧アプリ固有の権限は移さない |
| ブックマーク・スピードダイヤル | 既存を残して追加し、ID・URL重複を処理する。画像も資源上限を検証する |
| 検索プロバイダー | 旧版と同じ既知JSONを扱い、ID衝突・旧UIの仮ID`-1`・選択IDを調整。独自URL・既存の相対順を保つ |
| ユーザーエージェント・URL別ルール | 実在する既知JSONを検証し、既存ルールの優先関係を壊さず統合する |
| ジェスチャー・ユーザースクリプト | 対になるデータと参照、バイナリ・DBの形式を検証し既存優先で統合する。追加実装と単体回帰・計測APK生成まで成功。スクリプトを取込時に実行しない |
| 明暗テーマ | 内蔵テーマは移行対象。名前付きテーマの外部画像等は旧標準バックアップに含まれないため、資産のない参照をそのまま適用せず、現在のテーマ保持と理由を表示する |
| 保存先・権限・キャッシュ | 他アプリのSAF権限は継承できない。必要な保存先は選択し直し、派生キャッシュや未知DBは設定として展開しない |

旧来の復元入口も、限定的な統合を完全復元として無言で成功させない。対象と変更内容を示し、未対応データを明示する。移行先のデータを消す従来の直接展開へ戻すことはしない。

## 維持する機能とデータ

- ツールバーの位置・表示項目、カスタムボタン・アクション・ジェスチャー、既存の設定keyと数値ID、既存の明示的な配色設定を維持する。
- 移行元のYuzuと現在のCitrusのデータを削除しない。バックアップを検証する前の初期化、全DB消去、無関係なファイルへの展開を行わない。
- 設定の取込key、ブックマーク追加先、スピードダイヤルの重複処理、未対応の内容を明示する。未知のキャッシュや任意の直列化オブジェクトを設定として実行しない。
- 個人のバックアップ、閲覧内容、接続情報をGitへ含めない。コード回帰は人工のfixtureを使い、実データは最後に端末上で選択する。

## 既存課題との関係

| 残る課題 | 扱い |
| --- | --- |
| HTTP購読・304・一時失敗・再試行・回線切替 | [端末内HTTP計測2件](../app/src/androidTest/HTTP_SUBSCRIPTIONS.md)は実装・APK生成済みで端末未実行。バックオフ後の成功、外部通信・回線切替は引き続き残る |
| API37のLAN閲覧・DL・購読 | [明示設定導線](../legacy/LOCAL_NETWORK_PERMISSION.md)は実装・APK生成済み。API37での権限と実接続を別途確認する |
| 実Activity・プロセス・OS再起動、Doze | 今回の単なる画面遷移やSavedStateモデルの成功と分けて検証する |
| IME・戻る操作・ダウンロード・保存先権限 | UIを変えた箇所を含めて実操作を確認する。未実施項目は残す |
| 大規模リスト・端末での遅延とメモリ | 合成データや単体テストの時間を実サイトの速度とみなさず測定する |
| 他OS・横画面・別WebView・別ナビ方式 | SO-51D／Android 15だけの結果を一般化しない |
| 本番署名・配布 | デバッグAPKの検証とは別。未署名release APKを配布用完成品としない |

## 統合と再実機検証

1. 各分野の実装・相互の独立レビューを完了した。
2. Dockerのdebug・通常単体・全計測APK・release R8/lint・buildSrc単体が成功。解決graphと固定OSS通知、最終APK内の通知も確認した。
3. 次に秘密情報やバックアップの混入を確認し、検証済みの変更をGitHubへ反映する。
4. その後SO-51Dへデータを保持して更新し、追加28件と既存13件、Yuzu実バックアップ取込・日本語検索・モバイル広告・Material UI・既存操作を再検証する。API37のLAN確認は対応OSで別途行う。手順と結果を[実機確認](DEVICE_CHECKS.md)と[進捗](PROGRESS.md)へ反映する。

Googleの国別ドメイン統合は[Google公式](https://blog.google/products-and-platforms/products/search/country-code-top-level-domains/)、既存ViewsによるMaterial適用は[Android公式](https://developer.android.com/develop/ui/views/theming/look-and-feel)を参照する。
