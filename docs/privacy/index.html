CitrusBrowser プライバシーポリシー

最終更新日: 2026年11月28日

このプライバシーポリシーは、Android 向け Web ブラウザ「CitrusBrowser」（以下「本アプリ」）での情報の扱いを説明するものです。

  • 開発者: ajichama
  • 問い合わせ先: GitHub の Issues。公開の場所のため、個人情報は書かないでください。

1. 開発者は利用者のデータを集めません

本アプリには、解析・広告・クラッシュレポートの送信のための SDK は含まれていません。開発者は独自のサーバーを持たず、本アプリから開発者へ利用者のデータが送られることはありません。

2. 端末内に保存する情報

次の情報は、本アプリの機能のために端末内に保存されます。開発者へは送られません。

  • 閲覧履歴、ブックマーク、開いているタブ、スピードダイヤル、後で読むページ
  • 検索の履歴（検索候補の表示に使います）
  • Cookie、サイトのデータ、フォームの入力内容など、Web サイトが保存する情報
  • 設定、ユーザースクリプト、広告遮断のフィルタリストと設定
  • ダウンロードしたファイル（利用者が選んだ保存先）
  • 本アプリの動作記録（エラーの記録）。送信はしません

これらは、本アプリの設定や履歴の画面から消すか、Android の設定で本アプリのデータを消去するか、本アプリをアンインストールすると削除されます。プライベートモードや、サイトごとのデータの消去も使えます。

3. 本アプリが外部と通信する場合

本アプリは Web ブラウザなので、利用者が開く Web サイトと通信します。そのほか、次の場合に外部と通信します。送られた情報の扱いは、それぞれの送り先のプライバシーポリシーに従います。

  1. 検索候補: 検索欄に文字を入力すると、検索候補を表示するために、入力中の文字が、選んだ検索候補の提供元（Google、Microsoft Bing、DuckDuckGo のいずれか。初期設定は Google）へ送られます。設定の「検索候補」を「過去のクエリ」または「なし」にすると送られません。
  2. 検索: 検索すると、検索語が選んだ検索エンジンへ送られます。
  3. 広告・トラッカーの遮断のフィルタリスト: 広告遮断を有効にすると、フィルタリストを、それぞれの配布元（例: easylist.to、filters.adtidy.org、ublockorigin.github.io、raw.githubusercontent.com）から定期的にダウンロードします。このとき利用者のデータは送りませんが、通常の通信と同じく、配布元には IP アドレス等が届きます。利用者が追加したリストは、その配布元から取得します。
  4. ページの翻訳: 翻訳の操作をすると、表示中のページの URL が Google 翻訳へ送られます。
  5. リーダー表示・アイコン: リーダー表示を開いたとき、またはスピードダイヤルやホーム画面のショートカットのアイコンを取得するとき、表示中のサイトへ改めて接続します。
  6. セーフブラウジング: ページの表示に使う Android System WebView（Google 提供）のセーフブラウジング機能が、危険なサイトの確認のために Google と通信することがあります。
  7. ダウンロード: 利用者が選んだファイルを、その配信元から取得します。

4. 端末の権限

次の権限は、記載の目的にだけ使います。位置情報・カメラ・マイクは、Web サイトが求め、利用者が許可したときだけ使います。許可はいつでも Android の設定から取り消せます。

  • インターネット、ネットワークの状態: Web の閲覧、検索、ダウンロード、フィルタリストの更新
  • 位置情報: 地図などの Web サイトが位置情報を求め、利用者が許可したとき、そのサイトへ渡すため
  • カメラ、マイク、音声の設定: ビデオ通話などの Web サイトが求め、利用者が許可したとき
  • 通知、前景サービス: ダウンロード中に進み具合を表示し、画面を離れてもダウンロードを続けるため
  • アプリのインストールの要求: ダウンロードしたアプリ（APK）を利用者が開いたとき、Android のインストーラーへ渡すため
  • ローカルネットワーク（Android 17 以上）: 利用者が設定で選んだ場合に、家庭内の機器などのページを開くため
  • ストレージ（Android 9 以下のみ）: ダウンロードしたファイルやバックアップの保存
  • その他: 画面のスリープの防止、振動、ホーム画面へのショートカットの追加

5. Android のバックアップ

Android の設定でバックアップが有効な場合、本アプリのデータ（ブックマーク・履歴・設定など）が、Android の機能により利用者の Google アカウントへバックアップされることがあります。ログインの状態（Cookie）・サイトが保存したデータ・開いているタブ・キャッシュは、バックアップにも機種変更時の移行にも含めません。これは Google が提供する機能で、開発者はその内容を見られません。Android の設定でオフにできます。

6. 子どもについて

本アプリは 13 歳未満の子どもを対象としていません。

7. このポリシーの変更

内容を変えるときは、このページを更新し、最終更新日を改めます。大きな変更は、GitHub のリリースノートでもお知らせします。
