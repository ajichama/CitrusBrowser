# ホーム画面の外観と保持する設定

`res/raw/speeddial_css` へ形状・文字組み・フォーカス表示の上書きだけを追加した。HTML、DOMのID/クラス、JavaScript、`citrus:` リンク、データモデル、保存・取り込み処理は変更していない。

| 対象 | 変更前 | 変更後と保持点 |
| --- | --- | --- |
| 検索へのリンク | 小さい角丸・細い内側余白 | 大きい角丸と内側余白。入力フォームへの既存リンク、文字・背景・枠の色を保持 |
| サイトのタイル | 2pxの角丸と偏った影 | 16pxの角丸と控えめな影。列数・幅・margin・並び・画像寸法・サムネイルの表示設定を保持 |
| フォーカス | WebView標準の表示 | 標準表示を残し、検索/末尾操作の枠とタイル名の下線を追加。新しい固定色は使わない |
| 履歴・ブックマーク・設定 | 高さ30pxの絶対配置 | 折り返せる通常フローの操作。幅や翻訳・文字サイズに応じて高さを確保し、タイルとの重なりを避ける。リンク先と表示文言は保持 |

スタイルシートは従来どおり `base.css` → `custom.css` の順で読み込む。暗色設定、小アイコン表示、縦横の列数/列幅、文字サイズ、ヘッダー/検索/画像の非表示は後者の既存生成CSSで適用される。独自配色を新しい色で固定上書きせず、フォーカスや末尾リンクの境界線には既存の `currentColor` を使う。

静的確認では、既定/ロシア語のHTMLに同じID・リンク・CSS読込順が残ること、HTML生成側とcustom CSSの設定分岐を変更していないことを確認した。追加CSSの波括弧の対応とプロパティを点検し、担当差分の空白検査を通した。端末での見た目、暗色/小アイコン/列数切替、狭い画面と大きな文字、キーボードフォーカス、リンク操作は実行結果を別途記録する。静的確認だけで全操作や全OSの成功とは扱わない。
