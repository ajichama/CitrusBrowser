# ローカルネットワーク権限

Android 17 / API 37 以降では、targetSdk 37 の LAN 接続に OS の `ACCESS_LOCAL_NETWORK` 実行時権限が必要です。対象には WebView と OkHttp の通信も含まれます。[Android 公式仕様](https://developer.android.com/privacy-and-security/local-network-permission)（2026-11-03 更新）を確認しています。

設定 → ブラウザ設定の「ローカルネットワークへのアクセス」は API 37 以上にだけ表示します。端末内の実際の許可状態を表示し、OS 設定から戻った場合も再読込します。アプリ独自の許可フラグは保存せず、バックアップから許可状態を移しません。

利用者が項目を開き、理由を確認して「許可を要求」を押した時だけシステムへ要求します。拒否後もアプリは終了せず、再要求または「アプリ設定を開く」を利用者が選択できます。許可済みの場合の取消も OS 設定へ案内します。起動時の一律要求はありません。

今回の範囲は宣言と明示設定です。通信先の自動 LAN 判定、Worker からの画面表示、NDK による拒否原因判定は追加しません。一般の IOException/timeout を LAN 権限拒否と断定せず、通常のインターネット閲覧を一律に遮断しません。LAN 接続を利用する前にこの設定で許可してください。

API 36 以下では項目を表示せず、この権限を要求しません。Android 16 の旧 opt-in 向けに NEARBY_WIFI_DEVICES を追加要求することもありません。API 35 実機の検証だけでは API 37 の許可・拒否・取消動作を検証済みとはしません。API 37 端末またはエミュレーターで、未許可/許可/拒否/再要求/OS 設定からの変更・復帰を別途確認する必要があります。
